# 运力-运价预测模型项目
## 项目背景
2020 至 2022 年间，受新冠疫情影响，美国洛杉矶/长滩港口出现严重拥堵现象。这导致船舶平均等待时间大幅上升，同时推动美西航线运价（如 SCFI 指数）出现前所未有的剧烈波动。传统基于静态供需关系的运价预测模型难以解释这一波动规律，因此亟需引入港口“有效运力”视角，建立反映实际港口运行状态与航运市场关系的预测模型。
## 项目目标
本项目旨在构建基于港口实际吞吐能力的运力-运价动态模型，主要包含两大任务：
### 1. 构建港口“运力-有效运力”转化模型
量化拥堵、劳动力短缺等因素对实际可用运力的影响；
建立“有效运力”估算模型
### 2. 构建“运力-运价”预测模型
以有效运力为核心输入变量；
使用机器学习方法进行预测建模；
评估模型的适用性与稳健性
